01 / АРХИТЕКТУРА ПРОДУКТА

Прямой локальный канал между ИИ и Revit 2022–2027 API

Timsco Connector связывает Google Antigravity и открытую сессию Autodesk Revit 2022–2027 через локальный сервер MCP и версионный Windows Named Pipe. Вычисления выполняются внутри потокобезопасного ExternalEvent, а готовые C#-сценарии подгружаются в память без перезапуска программы.

Инженерная автоматизация, UI-инспектор и экономия квот
